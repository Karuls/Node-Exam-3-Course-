# Широковещательный WebSocket сервер

## Описание
WebSocket сервер который рассылает сообщения всем подключенным клиентам. Идеально подходит для чатов, уведомлений и онлайн-игр.

## Теория

### Что такое широковещание (broadcast)?
- Отправка одного сообщения всем подключенным клиентам
- В отличие от unicast (отправка одному клиенту)
- Полезно для чатов, уведомлений, обновлений в реальном времени

### Когда использовать широковещание?
- Чат-комнаты
- Онлайн-трансляции
- Уведомления для всех пользователей
- Обновления статуса системы
- Многопользовательские игры

### Как реализовано в коде:
1. Сервер хранит Map всех подключенных клиентов
2. При получении сообщения от одного клиента
3. Сервер перебирает всех клиентов и отправляет им сообщение
4. Можно исключить отправителя из рассылки

## Запуск и тестирование

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск сервера
```bash
node server.js
```
Сервер запустится на ws://localhost:8080

### 3. Запуск клиентов (в нескольких терминалах)
```bash
# Терминал 1
node client.js

# Терминал 2
node client.js

# Терминал 3
node client.js
```

### 4. Тестирование функционала

#### Тест 1: Подключение клиентов
- Запустите 3+ клиента
- Проверьте что каждый получает приветствие
- Проверьте что все клиенты видят уведомления о подключениях

#### Тест 2: Широковещание сообщений
- Отправьте сообщение с первого клиента
- Проверьте что все остальные клиенты получили сообщение
- Проверьте что отправитель видит подтверждение отправки

#### Тест 3: Отключение клиентов
- Закройте один клиент (Ctrl+C или введите "exit")
- Проверьте что остальные клиенты получили уведомление об отключении
- Проверьте что счетчик клиентов уменьшился

#### Тест 4: Системные сообщения
- Подождите 30 секунд
- Проверьте что все клиенты получили системное сообщение

### 5. Проверка через инструменты

#### Chrome DevTools
```javascript
// В консоли браузера
const ws = new WebSocket('ws://localhost:8080');
ws.onmessage = (event) => console.log(JSON.parse(event.data));

```


## Возможные проблемы

1. **Сообщения не доходят до всех клиентов**
   - Проверьте что broadcast() перебирает всех клиентов
   - Проверьте readyState === WebSocket.OPEN

2. **Утечки памяти**
   - Удаляйте клиентов из Map при отключении
   - Очищайте обработчики событий

3. **Проблемы с JSON**
   - Всегда используйте try-catch при парсинге
   - Проверяйте структуру сообщений

4. **Много клиентов - медленная работа**
   - Оптимизируйте broadcast (например, использовать Set вместо Map)
   - Рассмотрите разделение на комнаты (rooms)

### Добавление комнат (rooms)
```javascript

const rooms = {
    'general': new Set(),
    'gaming': new Set(),
    'support': new Set()
};
```

### Приватные сообщения
```javascript
// Отправка сообщения конкретному клиенту
function sendToClient(clientId, message) {
    // Найти клиента по ID и отправить сообщение
}
```

### История сообщений
```javascript
// Хранение последних 100 сообщений
const messageHistory = [];
function addToHistory(message) {
    messageHistory.push(message);
    if (messageHistory.length > 100) messageHistory.shift();
}
```
