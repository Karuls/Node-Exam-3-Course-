# Задание 1: Обработка POST-запроса с content-type: multipart/form-data

## Описание
Сервер для обработки форм с загрузкой файлов через multipart/form-data.

## Теория

### Что такое multipart/form-data?
Это метод кодирования данных формы, который позволяет отправлять файлы вместе с текстовыми данными. Используется когда в HTML-форме есть `<input type="file">`.

### Как работает?
1. Браузер разбивает данные на части (parts), разделенные специальной строкой-границей (boundary)
2. Каждая часть содержит свои заголовки (Content-Disposition, Content-Type) и содержимое
3. Сервер распознает границу и парсит каждую часть отдельно

### Отличие от других content-types:
- **application/x-www-form-urlencoded**: только текстовые данные, кодируются как `key=value&key2=value2`
- **multipart/form-data**: поддерживает файлы, использует границы для разделения частей
- **application/json**: только JSON данные, не поддерживает файлы

## Структура проекта
```
server.js          - основной файл сервера
package.json       - зависимости
uploads/           - папка для сохранения загруженных файлов
README.md          - эта документация
```

## Инструкция по запуску

### 1. Установка зависимостей
```bash
npm install
```

### 2. Создание папки для загрузок
```bash
mkdir uploads
```

### 3. Запуск сервера
```bash
node server.js
```

Сервер запустится на порту 3000: http://localhost:3000

## Тестирование

### Способ 1: Через браузер
1. Откройте http://localhost:3000
2. Заполните форму:
   - Имя пользователя
   - Email
   - Выберите файл для загрузки
3. Нажмите "Отправить"
4. Проверьте:
   - Консоль сервера (должны увидеть полученные данные)
   - Папку uploads/ (файл должен сохраниться)
   - Ответ в браузере (JSON с информацией)

### Способ 2: Через curl (командная строка)
```bash
curl -X POST http://localhost:3000/upload \
  -F "username=testuser" \
  -F "email=test@example.com" \
  -F "file=@testfile.txt"
```

### Способ 3: Через Postman
1. Метод: POST
2. URL: http://localhost:3000/upload
3. Body → form-data:
   - username: testuser
   - email: test@example.com
   - file: выбрать файл

## Дополнительные возможности

### Ограничение размера файла
В файле server.js можно настроить:
```javascript
maxFileSize: 10 * 1024 * 1024 // 10MB максимум
```

### Проверка типов файлов
Добавить проверку MIME-типов или расширений.

### Сохранение с оригинальным именем
Опция `keepExtensions: true` сохраняет расширения файлов.

## Возможные проблемы и решения

1. **Файлы не сохраняются**
   - Проверьте права на запись в папку uploads/
   - Убедитесь что папка существует

2. **Ошибка "Cannot find module 'formidable'"**
   - Выполните `npm install`

3. **Сервер не запускается**
   - Проверьте что порт 3000 свободен
   - Попробуйте изменить порт в server.js

4. **Большие файлы не загружаются**
   - Увеличьте лимит размера в настройках formidable
   - Проверьте настройки сервера
